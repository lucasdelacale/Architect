# Workflow: Análise de Campanha

Versão: 1.1 | Data: 2026-08-06 | Command: `/campaign-analysis` | Source: `~/.config/opencode/commands/campaign-analysis.md`

## Objetivo

Análise completa de campanha multicanal com recuperação de contexto, estratégia, performance, causalidade e revisão.

## Fluxo

1. **knowledge-manager** — recupera contexto no vault.
2. **growth-strategist** — perguntas, hipóteses e metodologia. *(Pulável se não houver contexto relevante.)*
3. **performance-analyst** — framework das 4 perguntas.
4. **experimentation-scientist** — causalidade. *(Somente se houver hipótese causal.)*
5. **critical-reviewer** — auditoria independente.
6. **communication-strategist** — mensagem executiva.
7. **creative-director** — material visual final.

## Regras

- 3 a 7 estágios conforme complexidade.
- Cada estágio retorna síntese acionável (não rascunho).
- Entrega: síntese, decisões recomendadas, próximos passos.
- Para análises de campanha específica, usar campaign-timeline como formato de entrega.
