# Architect

> Um sistema operacional adaptativo de Inteligência Artificial para
> produtividade, análise de dados, growth, mídia paga e gestão do
> conhecimento.

## O que é o Architect?

O Architect é uma camada de orquestração construída sobre o OpenCode que
transforma modelos de IA em uma equipe especializada de agentes, skills
e workflows. Seu objetivo é aumentar produtividade, qualidade analítica
e reaproveitamento de conhecimento ao longo do tempo.

Em vez de depender de um único modelo de IA, o Architect utiliza uma
arquitetura modular capaz de evoluir continuamente.

## Principais funcionalidades

-   Equipe de subagentes especializados.
-   Integração profunda com Obsidian.
-   Memória persistente utilizando Supermemory.
-   Orquestração inteligente utilizando OmO (Oh My OpenAgent).
-   Sistema de evolução contínua da arquitetura.
-   Geração de relatórios HTML e dashboards.
-   Análises estatísticas e estudos de mídia.
-   Otimização automática do uso dos modelos de IA.

## Filosofia do projeto

-   Modelos são substituíveis.
-   Conhecimento é um ativo estratégico.
-   A arquitetura é mais importante do que o modelo utilizado.
-   O sistema deve evoluir junto com o usuário.

## O que é o OmO?

OmO (Oh My OpenAgent) é responsável pela orquestração dos agentes,
skills e workflows do sistema. Ele permite delegar tarefas de forma
inteligente, reduzindo consumo de modelos premium e aumentando a
modularidade do projeto.

## O que é o Supermemory?

Supermemory adiciona memória persistente ao Architect, permitindo
recuperar conhecimento acumulado, histórico de projetos e contexto
relevante entre diferentes tarefas.

## O que é o Obsidian?

O Obsidian funciona como a principal base de conhecimento do projeto.
Nele podem ser armazenados:

-   análises de campanhas;
-   estudos estatísticos;
-   workflows;
-   documentação;
-   aprendizados;
-   relatórios.

## Como instalar

1.  Instale o OpenCode.
2.  Clone este repositório.
3.  Instale o OmO.
4.  Instale o Supermemory.
5.  Configure o Obsidian como base de conhecimento.
6.  Execute o prompt principal do Architect.

## Fluxo de utilização

O usuário não precisa chamar agentes ou skills manualmente. Basta
descrever o problema que deseja resolver.

O Architect será responsável por:

-   selecionar o modelo ideal;
-   selecionar os agentes necessários;
-   selecionar as skills relevantes;
-   executar o workflow apropriado.

## Architect Evolution System

O Architect possui um sistema de melhoria contínua responsável por:

-   identificar gargalos;
-   propor novos agentes;
-   sugerir automações;
-   otimizar workflows;
-   otimizar a utilização dos modelos;
-   auditar a arquitetura do sistema.

Nenhuma alteração estrutural é realizada sem aprovação do usuário.

## Objetivo

Construir uma organização adaptativa de Inteligência Artificial capaz de
evoluir continuamente, aumentar produtividade e preservar conhecimento
ao longo do tempo.
