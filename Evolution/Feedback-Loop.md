# Feedback Loop

**Versão:** 1.0
**Data de criação:** 2026-08-06
**Propósito:** Registrar feedbacks sobre conclusões do sistema para melhoria contínua de agentes e workflows.

---

## Como usar

1. **Ao validar uma conclusão:** Registre como "Acerto" com evidência.
2. **Ao refutar uma conclusão:** Registre como "Erro" com motivo e lição aprendida.
3. **Ao revisar agentes:** Consulte feedbacks para identificar padrões de erro.
4. **Ao evoluir o sistema:** Use feedbacks para priorizar melhorias.

---

## Tipos de Feedback

| Tipo | Descrição | Ação |
|---|---|---|
| ✅ **Acerto** | Conclusão validada por dados ou evento posterior | Registrar evidência |
| ❌ **Erro** | Conclusão refutada por dados ou evento posterior | Registrar motivo e lição |
| ⚠️ **Incerteza** | Conclusão não pode ser validada ainda | Marcar para reavaliação |
| 🔄 **Revisão** | Conclusão precisa ser reavaliada com novos dados | Agendar reavaliação |
