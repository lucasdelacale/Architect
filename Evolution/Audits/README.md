# Audits

Relatórios de auditoria completa da arquitetura do Architect (sob demanda).

Gerar com: `/evolution-audit`

Formato sugerido: `YYYY-MM-DD Auditoria.md`

Cada auditoria deve cobrir: arquitetura atual, padrões de uso, gargalos, agentes/skills pouco usados, oportunidades de automação, distribuição de modelos e propostas com problema → solução → benefício → esforço.
