# Skill: HTML Report System

Versão: 1.0 | Data: 2026-08-04 | Source: `~/.config/opencode/skills/html-report-system/SKILL.md`

## Propósito

Componentes, layouts e padrões visuais para relatórios executivos.

## Gatilhos

Geração de relatórios, apresentações, dashboards e materiais visuais em HTML/CSS.

## Padrão executivo

- Narrativa: contexto → achados → recomendação.
- Hierarquia visual clara.
- Paleta limitada e acessível.
- Data, fonte e responsabilidade na página.

## Design tokens

`--color-primary: #0B3D2E` | `--color-accent: #C8A24B` | `--font-sans: 'Inter'`

## Componentes

Header, KPI cards, charts, callouts, tables, footer.

## Regras

- Nunca placeholders genéricos.
- Dashboard sem narrativa = não entregar.
