# Skill: Data Analysis

Versão: 1.0 | Data: 2026-08-04 | Source: `~/.config/opencode/skills/data-analysis/SKILL.md`

## Propósito

Tratamento de dados, estatística e visualização.

## Gatilhos

Limpeza de dados, estatística descritiva/inferencial, testes de hipótese, causalidade, visualização.

## Etapas

Entender → limpar → explorar → analisar → visualizar → comunicar.

## Regras

- Reportar incerteza e limitações.
- Não afirmar causalidade sem método causal.
- Gráficos com título, eixo rotulado e fonte.
