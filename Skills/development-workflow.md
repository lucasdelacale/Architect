# Skill: Development Workflow

Versão: 1.0 | Data: 2026-08-04 | Source: `~/.config/opencode/skills/development-workflow/SKILL.md`

## Propósito

Git, código e organização técnica de projetos.

## Gatilhos

Desenvolvimento, automações, scripts, APIs, integrações, versionamento, arquitetura de projetos.

## Git

- Commits pequenos, mensagem no imperativo.
- `main` estável; `feature/<nome>` para trabalho novo.
- Nunca commitar segredos ou artefatos gerados.
- Só commit/push/PR quando solicitado.

## Estrutura

- Responsabilidades separadas (dados, lógica, apresentação, config).
- `.env` nunca versionado.
- Dependências explícitas.
- Testes junto do código.

## Regras

Entender o problema antes de codificar. Preferir a solução mais simples que funciona.
