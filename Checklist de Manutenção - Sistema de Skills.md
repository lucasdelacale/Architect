# Checklist de Manutenção - Sistema de Skills

## Mensal
- [ ] Verificar se todas as skills estão funcionando
- [ ] Testar 2-3 tarefas com ativação automática
- [ ] Revisar logs de uso (se disponíveis)
- [ ] Verificar se skill briefing está coletando contexto adequadamente

## Trimestral
- [ ] Revisar descriptions das skills
- [ ] Atualizar tabelas de decisão
- [ ] Verificar se novas skills são necessárias
- [ ] Documentar mudanças no vault

## Anual
- [ ] Revisão completa da arquitetura
- [ ] Consolidação de skills não utilizadas
- [ ] Atualização de dependências

## Responsável
- **Owner:** Sysyphus
- **Revisão:** Odysseus (estratégica)
- **Auditoria:** Atena (qualidade)
